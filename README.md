# Character Sync

SillyTavern 扩展：切换角色时自动同步 UI 主题、聊天背景和 API 连接配置。

## 功能

- **主题同步**：切换角色时自动切换 UI 主题
- **背景同步**：切换角色时自动切换聊天背景图片
- **API 同步**：切换角色时自动切换 API 连接配置（通过 Connection Manager 的 /profile 命令）
- **可视化绑定面板**：在扩展设置中为每个角色分别配置主题、背景和 API
- **一键重置**：一键恢复所有设置为默认值

## 安装

将整个 `character_sync` 文件夹放入 SillyTavern 的 `data/default-user/extensions/` 目录下，然后重启 SillyTavern 或在扩展面板中启用。

## 使用方法

1. 打开 SillyTavern → 扩展设置面板
2. 展开 **Character Sync** 面板
3. 勾选需要启用的同步选项（主题 / 背景 / API）
4. 在角色列表中为每个角色选择对应的主题、背景和 API 配置
5. 切换角色时，配置会自动生效
